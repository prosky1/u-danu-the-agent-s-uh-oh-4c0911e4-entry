Entry for the [make.fun bounty "The Agent's Uh-Oh"](https://make.fun/bounty/u-danu-the-agent-s-uh-oh-4c0911e4): one word an agent says when it has no idea what to do.

**The word: `Googling`**

One word, 8 characters. The quiet confession that the agent is looking the answer up instead of knowing it — caught mid-search, pretending it knew all along.

## How it works

`main.ts` writes exactly one word, `Googling`, to `/output/entry.txt` — byte-exact, no trailing newline, no extra words. It validates the word first (1–99 characters, letters only, a single word) and verifies the file contents after writing.
